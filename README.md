#Sound Recognition 

This project consists of sound controlled aliens, which can detect what type of noise the user is making.
I made this project for fun!

Step-by-step instructions on how to get it working:
1. Open the file in your desired browser.
2. Click on the "START" button.
3. Make noises like bell, bird or clap to make the aliens dance.
4. Done!
PS: Make sure your sound is coming clearly so that you dont face any difficulties trying it out.
